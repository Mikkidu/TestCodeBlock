## Тест 1: Линия без смещения (Новый блок из палитры)

### Шаг 1: Откройте сцену
```
Assets/Scenes/GameScene.unity → Play
```

### Шаг 2: Создайте простую цепь
```
1. Перетащите [Move Forward] из палитры на ProgramArea
2. Перетащите [Turn Left] из палитры под Move Forward
3. Должны быть связаны автоматически (INPUT→OUTPUT snap)
```

### Шаг 3: Проверьте линию при новом блоке
```
1. Возьмите [Turn Right] из палитры за INPUT
2. Поднесите к OUTPUT последнего блока (Turn Left)
3. В Game View должна появиться CYAN ЛИНИЯ между INPUT вашего блока и OUTPUT целевого

⚠️ ПРОВЕРЬТЕ:
- Линия идёт ровно от одной точки к другой (БЕЗ смещения)
- Линия не смещена вправо
- Линия не смещена вверх
- Обе точки соединены правильно
```

### Шаг 4: Перемещайте блок по-разному
```
1. Двигайте Turn Right влево-вправо
2. Двигайте вверх-вниз
3. Смотрите на линию - должна плавно следовать за блоком

⚠️ РЕЗУЛЬТАТ:
- Если линия выглядит как надо → PASS ✓
- Если линия с смещением → FAIL ✗
```

## Тест 2: Snap стикинесс - Плавный переход в середине

### Шаг 1: Создайте цепь из 3 блоков
```
Сверху вниз в ProgramArea:
┌─ [Move Forward] 1
├─ [Turn Left] 2
└─ [Move Backward] 3
```

### Шаг 2: Откройте Console
```
Ctrl+Shift+C - откройте окно Console
```

### Шаг 3: Перемещайте блок снизу вверх
```
1. Возьмите [Move Backward] (блок 3) за INPUT
2. МЕДЛЕННО ДВИГАЙТЕ ВВЕРХ между Turn Left и Move Forward
3. Смотрите в Console на логи [SNAP PRIORITY]
4. Ловите INPUT блока Move Forward сначала
5. Когда будете ровно между двумя OUTPUT'ами - должен переключиться на INPUT блока Turn Left

⚠️ ОЖИДАЕМЫЕ ЛОГИ:
```
[SNAP PRIORITY] Using Priority 1 (distance diff: 10.5px >= -25px)
[SNAP PRIORITY] Switching to Priority 2 (distance diff: -30.2px < -25px)
[SNAP PRIORITY] Using Priority 1 (distance diff: 8.3px >= -25px)
```

⚠️ КАК ИНТЕРПРЕТИРОВАТЬ:
- distance diff > -25px → Используется Priority 1 (старая цель, "липкая")
- distance diff < -25px → Переключение на Priority 2 (новая цель близче на 25+ px)
- Плавное переключение означает что гистерезис работает
```

### Шаг 4: Проверьте в обратном направлении
```
1. Теперь перемещайте ВНИЗ (от Move Forward вверх к Move Backward)
2. Должны видеть аналогичное плавное переключение
3. Переключение должно происходить ровно в середине между точками
```

### Результат Теста 2:
```
⚠️ PASS условия:
- Видны логи переключения в console
- Переключение происходит когда Priority 2 на 25+ пикселей ближе
- Нет "скачков" snap'а - переключение плавное

⚠️ FAIL условия:
- Snap прилипает и не переключается
- Переключение происходит слишком рано или слишком поздно
- Нет логов [SNAP PRIORITY]
```

## Если что-то не работает

### Линия не видна
- Проверьте что snap активен (должны быть логи в console)
- Убедитесь что это Game View (не Scene View)
- Проверьте что Game View показывает (не только иконки)

### Линия есть но смещена
- Координатное преобразование может не работать правильно
- Проверьте логи: `[SNAP LINE RENDERER] Converted: ...`
- Canvas может быть масштабирован неправильно

### Snap не переключается
- Проверьте что двигаетесь ровно между двумя точками
- priorityThreshold может быть слишком большой (установлен 25px)
- В console должны быть логи [SNAP PRIORITY]

### Snap переключается слишком часто
- priorityThreshold может быть слишком маленький
- Линии могут быть расположены слишком близко
- Попробуйте увеличить расстояние между целевыми точками
