# Быстрая отладка визуализации - 3 простых шага

## Шаг 1: Откройте Console и скопируйте логи

```
1. Play в сцене
2. Откройте Console (Ctrl+Shift+C)
3. Перетащите блок за INPUT к OUTPUT другого блока
4. Скопируйте все логи которые начинаются с [BLOCK UI VISUALS]
```

**Ожидаемые логи:**
```
[BLOCK UI VISUALS] Can snap! Type: InputToOutput, Distance: 23.49px
[BLOCK UI VISUALS] Input pos: (XXX, YYY, ZZZ)
[BLOCK UI VISUALS] Output pos: (AAA, BBB, CCC)
[BLOCK UI VISUALS] Target pos: (DDD, EEE, FFF)
[VISUALIZER] SNAP ACTIVE: ...
[VISUALIZER] INPUT→OUTPUT: from (...) to (...)
```

## Шаг 2: Проверьте Gizmos в Scene View

```
1. Переключитесь на Scene View (вкладка сверху)
2. Убедитесь что Gizmos включены (кнопка в сцене)
3. Перетащите блок за INPUT
4. Смотрите на Scene View - должны быть КРУЖКИ и ЛИНИЯ
```

**Что должно быть видно в Scene View:**
- ✓ Кружок (круг из линий) в позиции INPUT перетаскиваемого блока
- ✓ Кружок (круг из линий) в позиции OUTPUT целевого блока
- ✓ Линия между кружками (цветная: cyan или жёлтая)

## Шаг 3: Посмотрите в Game View с включенными Gizmos

```
1. Вернитесь в Game View
2. В верхнем правом углу найдите кнопку Gizmos
3. Убедитесь что она с галочкой (включена)
4. Перетащите блок за INPUT
5. Смотрите в Game View - должны быть видны линии и кружки
```

## Интерпретация координат из логов

Из примера логов:
```
[BLOCK UI VISUALS] Input pos: (450.5, 234.2, 0.0)
[BLOCK UI VISUALS] Target pos: (620.3, 402.1, 0.0)
```

Это означает:
- INPUT перетаскиваемого блока находится в точке (450.5, 234.2)
- OUTPUT целевого блока находится в точке (620.3, 402.1)
- Линия должна быть нарисована между этими точками

## Если логов нет или они другие

**Логи не появляются:**
- `programArea` может быть null
- `lineVisualizer` может быть null
- snap может быть false

**Решение:** Нужно убедиться что SnapLineVisualizer компонент добавлен на ProgramArea

## Отправьте этот вывод Console

После выполнения этих шагов отправьте:
1. Полный список логов из Console (копировать выделить и Ctrl+C)
2. Скажите видны ли кружки в Scene View? (ДА/НЕТ)
3. Видна ли линия в Game View? (ДА/НЕТ)
4. Скажите какого цвета линия если видна (cyan/yellow/другой)

Это поможет определить где именно проблема.

---

**Примечание:** Если видны кружки в Scene View но не в Game View → проблема с масштабом или Gizmos не включены в Game View
