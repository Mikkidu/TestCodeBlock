# #3b-1: CodeBlocks - Доработанная механика блоков в ProgramArea

**Статус**: 📋 **ПЛАНИРОВАНИЕ**
**Приоритет**: 🔴 **КРИТИЧНЫЙ**
**Срок**: Февраль 2026 (неделя 1-2)

---

## 📋 СУТЬ МЕХАНИКИ

- Одна точка входа (невидимый корень в ProgramArea)
- Цепочки: вход блока → выход предыдущего
- Магнетизм коннекторов для быстрого подключения
- Умная вставка между блоками по оси Y
- Правильное выравнивание при любых операциях

---

## 🎯 ГРУППЫ ЗАДАЧ

### ГРУППА 1: Базовое управление цепью (25%)

**1.1 Инициализация входной точки**
- Создать невидимый корень (фиктивный выход) в ProgramArea
- Время: 2-3ч | Метрика: видна точка входа (Debug визуализация)
- Шаги:
  - Создать `ProgramAreaInputPoint` компонент
  - Позиция (0, 0) относительно ProgramArea
  - Интегрировать в `CodeBlocksWindow.OnInit()`
  - Тест: видна ли красная точка при запуске окна?

**1.2 Подключение блока к цепи**
- При сбросе блока в ProgramArea → автоматически подключить входом к последнему выходу
- Время: 3-4ч | Метрика: блок подключена с видимой линией
- Шаги:
  - `GetLastBlockInChain()` метод
  - `ConnectBlocks(lastOutput, newBlockInput)` логика
  - Вызвать выравнивание после подключения
  - Тест: блок подключается в конец?

**1.3 Отключение блока из цепи**
- При извлечении блока → отключить входы/выходы, сросить цепь
- Время: 3-4ч | Метрика: цепь остается целой после удаления
- Шаги:
  - `DisconnectBlock()` метод
  - Получить prevBlock и nextBlock
  - Сросить: prevBlock.output → nextBlock.input
  - Выравнять остальную цепь

**1.4 Выравнивание блоков**
- Все блоки в цепи выравнены вертикально, X зафиксирован
- Время: 2-3ч | Метрика: блоки выстроены по Y от 0 вниз
- Шаги:
  - `AlignChain(startBlock)` метод
  - Y += (предыдущий Y + высота предыдущего)
  - Вызывать после любого изменения цепи

---

### ГРУППА 2: Перетаскивание (30%)

**2.1 Захват блока и иерархия**
- При начале drag → все блоки цепи становятся дочерними к перетаскиваемому
- Время: 2-3ч | Метрика: цепь движется как единый объект
- Шаги:
  - `GrabChain(draggedBlock)` при начале drag
  - SetParent() для всех блоков в цепи
  - Сохранить originalParent

**2.2 Движение в ProgramArea**
- Блок следует за мышью, не выходит за границы
- Время: 1-2ч | Метрика: плавное движение в пределах области
- Шаги:
  - Input.mousePosition → мировые координаты
  - Ограничить Clamp() границами ProgramArea
  - Вызывать `TryInsertBetween()` во время движения

**2.3 Отпускание в ProgramArea**
- Блок интегрирован в цепь, выравнен, дочерний к ProgramArea
- Время: 2-3ч | Метрика: блок остается в цепи после drop
- Шаги:
  - `DropInArea()` при отпускании
  - Восстановить SetParent(ProgramArea)
  - Если не подключена через магнетизм → присоединить к последнему
  - Выравнять цепь

**2.4 Отпускание вне ProgramArea**
- Блок из палитры вернуть в палитру, из программы удалить
- Время: 1-2ч | Метрика: блок исчезает или возвращается
- Шаги:
  - Проверить `IsPointInsideArea()`
  - Если вне → Destroy + отсоединить из цепи
  - Если из палитры → вернуть в палитру

---

### ГРУППА 3: Магнетизм коннекторов (25%)

**3.1 Snap в начало цепи**
- Блок близко к InputPoint → автоматический snap
- Время: 2-3ч | Метрика: блок снап'ится в начало
- Шаги:
  - Расчитать расстояние до InputPoint
  - Если < magnetDist → визуализировать линию
  - При drop → автоматический snap

**3.2 Snap в конец цепи**
- Блок близко к выходу последнего блока → snap
- Время: 2-3ч | Метрика: блок снап'ится в конец
- Шаги:
  - Получить последний блок, расчитать расстояние до выхода
  - Если < magnetDist → визуализировать линию
  - При drop → snap и подключение

**3.3 Snap в середину цепи**
- Блок близко к выходу любого блока → snap в середину
- Время: 3-4ч | Метрика: блок вставлен между двумя, все выравнены
- Шаги:
  - Итерировать по всем выходам в цепи
  - Найти минимальное расстояние < magnetDist
  - `InsertAfterBlock(targetBlock, newBlock)` при drop
  - Подсоединить: targetBlock.output → newBlock.input → nextBlock.input

**3.4 Визуализация линий магнитизма**
- Во время drag показать линию притяжения
- Время: 1-2ч | Метрика: линия видна при близости к магниту
- Шаги:
  - `MagnetismVisualizerLine` компонент
  - Включить при drag near, отключить при drag away
  - Цвет: оранжевый/красный

---

### ГРУППА 4: Вставка между блоками по оси Y (20%)

**4.1 Определение позиции по Y**
- Если блок выше последнего блока в цепи → определить позицию вставки
- Время: 2-3ч | Метрика: правильно определяется Y позиция
- Шаги:
  - Во время drag: получить текущую Y позицию блока
  - Сравнить с Y последнего блока
  - Если меньше → начать поиск вставки

**4.2 Поиск целевого блока**
- Пройти по цепи снизу вверх и найти куда вставить
- Время: 2-3ч | Метрика: найден правильный целевой блок
- Шаги:
  - `FindInsertTargetBlock(draggedBlockY)` метод
  - Итерировать от конца к началу
  - Если Y целевого > draggedBlockY → это целевой
  - Вернуть найденный блок

**4.3 Вставка и выравнивание**
- Вставить блок между найденными блоками
- Время: 2-3ч | Метрика: блок вставлен, цепь выравнена
- Шаги:
  - `InsertBetween(draggedBlock, targetPosition)` метод
  - Если блок уже в цепи → отключить его
  - Подсоединить: targetBlock.output → new.input → nextBlock.input
  - Выравнять цепь

**4.4 Динамическая вставка при движении**
- Вызывать логику вставки во время drag, не требует отпускания
- Время: 1-2ч | Метрика: блок динамически встает на место при движении
- Шаги:
  - При drag in ProgramArea: `TryInsertBetween()`
  - Проверить условие: blockY < lastBlockY && blockIsInArea
  - Если да → найти и вставить
