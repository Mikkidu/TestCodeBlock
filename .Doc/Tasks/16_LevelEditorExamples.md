# Task #16: Level Editor примеры и интеграция

**Status**: Ready for Implementation
**Priority**: 🟠 HIGH
**Blockers**: #14, #15 (редактор и tools должны быть готовы)
**Timeline**: 15-16 января (1 день)

---

## Описание

Создать 3-5 примеров уровней для демонстрации редактора и проверки интеграции.

Каждый пример должен:
1. Быть создан в Level Editor (#14)
2. Экспортирован в JSON (#15)
3. Загружен и протестирован в игре

---

## Шаги реализации

### День 1 (15-16 янв)

1. **Создать level_001_simple**
   - Открыть Level Editor
   - Размещать terrain блоки
   - Установить Start (0,0) East
   - Установить Finish (4,4)
   - Экспортировать в JSON
   - Тест в игре: выполнить программу, проверить что робот дошёл

2. **Создать level_002_walls**
   - Аналогично, добавить Objects (Wall)
   - Убедиться что объекты размещены на Ground

3. **Создать level_003_pit**
   - Добавить Pit terrain тип
   - Убедиться что объекты не могут быть на Pit

4. **Создать level_004_triggers**
   - Button с параметром color="Red"
   - Door с параметром color="Red"
   - Тест в игре: проверить что门 открывается при нажатии кнопки

5. **Создать level_005_complex**
   - Комбинация всех элементов

6. **Полное тестирование**
   - Каждый уровень загружается
   - Робот может быть запущен
   - Визуально уровень выглядит корректно
   - Нет ошибок валидации
