## 📋 ОПИСАНИЕ

Реализовать систему управления цепью блоков с **ProgramAreaManager** - компонентом, который отслеживает цепи блоков, управляет подключениями и выравниванием при drag&drop операциях.

Эта механика критична для интеграции CodeBlocks в play-united, где нужна полная поддержка:
- Перетаскивания блоков в ProgramArea
- Правильного выравнивания при добавлении/удалении
- Магнетизма коннекторов при движении
- Умной вставки между блоками по оси Y

---

## 🎯 ОБЩИЙ ПЛАН (4 ГРУППЫ ЗАДАЧ)

### ГРУППА 1: Базовое управление цепью (25%)
- **Улучшить BlockConnector**: добавить connectedTo field, методы Connect/Disconnect
- **Методы в BlockUIBase**: GetInputConnector, GetNextBlock, GetPreviousBlock
- **Логика в ProgramAreaManager**: GetLastBlockInChain, GetBlocksInChain, GetBlockPositionInChain
- **Подключение блоков**: ConnectBlocks, AppendBlockToChain, PrependBlockToChain

📄 **Документация**: [26_Step1_InputPointInitialization.md](26_Step1_InputPointInitialization.md)
📄 **Документация**: [26_Step2_ConnectLogic.md](26_Step2_ConnectLogic.md)

### ГРУППА 2: Перетаскивание (30%)
- **Захват и иерархия**: SetParent() для цепи при начале drag
- **Движение в ProgramArea**: следование мышью, ограничение границами
- **Отпускание в ProgramArea**: интеграция в цепь через AppendBlockToChain
- **Отпускание вне ProgramArea**: удаление или возврат в палитру

### ГРУППА 3: Магнетизм коннекторов (25%)
- **Snap в начало цепи**: к InputPoint
- **Snap в конец цепи**: к выходу последнего блока
- **Snap в середину цепи**: между любыми двумя блоками
- **Визуализация**: линии притяжения (SnapLineRenderer)

### ГРУППА 4: Вставка между блоками по оси Y (20%)
- **Определение Y позиции**: если блок выше последнего → поиск вставки
- **Поиск целевого блока**: `FindInsertTargetBlock()` - итерация снизу вверх
- **Вставка и выравнивание**: `InsertBetween()` - переподключение коннекторов + align
- **Динамическая вставка**: `TryInsertBetween()` во время drag, не требует отпускания

## 🔗 АРХИТЕКТУРА

```
InputPoint (Transform, отдельный GameObject в префабе)
    ↓
ProgramAreaManager.SetFirstBlock(block)
    ↓
BlockUI.outputConnector.ConnectTo(NextBlock.inputConnector)
    ↓ (NavigationGetNextBlock)
BlockUI.outputConnector.connectedTo.GetConnectedBlock()
    ↓ (Цепь может быть глубокой)
... более блоков
```

**Ключевые компоненты**:
- **InputPoint**: Transform для позиции первого блока (вручную в префабе)
- **ProgramAreaManager**: управление цепью, методы доступа
- **BlockConnector**: улучшен - connectedTo, методы Connect/Disconnect
- **BlockUIBase**: методы навигации по цепи (GetNextBlock, GetPreviousBlock)
