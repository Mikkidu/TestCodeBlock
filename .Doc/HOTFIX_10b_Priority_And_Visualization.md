## Что было исправлено

### 1. ❌ Критичная ошибка: Неправильный порядок проверки snap

**Проблема:**
- Блоки магнитились выходом ко входам (OUTPUT→INPUT)
- Должны были магниться входом к выходам (INPUT→OUTPUT)
- Это неправильный приоритет для вставки в цепь

**Решение:**
Поменян порядок проверки в `OnDrag()` и `OnEndDrag()`:

```
ДО:
Priority 1: OUTPUT → INPUT (вставка в начало)
Priority 2: INPUT → OUTPUT (добавление в конец)

ТЕПЕРЬ:
Priority 1: INPUT → OUTPUT (вставка в середину/конец) ✓
Priority 2: OUTPUT → INPUT (вставка в начало)
```

**Файл:** `BlockUI.cs` (строки 274-284, 344-370)

### 2. ✅ Visualizer: Линия магнитизма видна в Game View

**Было:** Линия видна только в Scene View и только при движении курсора (Debug.DrawLine)

**Стало:**
- Новый компонент `SnapLineVisualizer` в ProgramArea
- Кэширует информацию о снапе
- Рисует линию каждый кадр в Game View
- Линия видна постоянно пока snap активен

**Файлы:**
- ✓ Создан: `SnapLineVisualizer.cs` (новый компонент)
- ✓ Обновлён: `BlockUI.cs` (интеграция с визуализатором)
- ✓ Обновлён: `Assembly-CSharp.csproj` (добавлен новый файл)
