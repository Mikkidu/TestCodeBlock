# Инструкции для тестирования новой логики выбора snap'а

## Тест 1: Ситуация из скриншота (КРИТИЧНЫЙ)

### Шаг 1: Откройте сцену
```
Assets/Scenes/GameScene.unity → Play
```

### Шаг 2: Создайте цепь из 3 блоков
```
Сверху вниз в ProgramArea:
1. [Move Forward] (жёлтый)
2. [Turn Left] (жёлтый)
3. [Move Backward] (жёлтый)
```

### Шаг 3: Возьмите новый блок из палитры
```
Возьмите [Turn Right] за INPUT и поднесите выше блока #1
```

### Шаг 4: ВАЖНО - Проверьте логирование
```
Смотрите в Console (Ctrl+Shift+C):

Должны видеть логи типа:
[SNAP CHOICE] INPUT→OUTPUT closer (X.Xpx < Y.Ypx) → Move Forward
ИЛИ
[SNAP CHOICE] INPUT→OUTPUT closer (X.Xpx < Y.Ypx) → Turn Left
ИЛИ
[SNAP CHOICE] INPUT→OUTPUT closer (X.Xpx < Y.Ypx) → Move Backward
```

### Шаг 5: РЕЗУЛЬТАТ ТЕСТА
```
✓ PASS:
  - Красный блок выше Move Forward → магнитится к Move Forward ✓
  - Красный блок выше Turn Left → магнитится к Turn Left ✓
  - Красный блок выше Move Backward → магнитится к Move Backward ✓
  - Логи в console показывают какой блок выбран и почему

✗ FAIL:
  - Линия рисуется не к тому блоку
  - Нет логов [SNAP CHOICE] в console
  - Логи неправильные
```

## Тест 2: Плавное переключение между OUTPUT'ами

### Шаг 1: Создайте цепь из 5 блоков
```
1. [Move Forward]
2. [Turn Left]
3. [Move Backward]
4. [Turn Right]
5. [Move Forward]
```

### Шаг 2: Возьмите блок #3 (Move Backward) за INPUT

### Шаг 3: Медленно двигайте вверх между #2 и #4

```
Позиция #1
Позиция #2  ←─ Turn Left (OUTPUT)
         ↑
    Сюда переносим #3
         ↑
Позиция #3  ←─ Move Backward (OUTPUT - это наш блок!)
Позиция #4  ←─ Turn Right (INPUT)
```

### Шаг 4: ВАЖНО - Смотрите логи
```
Когда Move Backward ровно между Turn Left и Turn Right, должны видеть:

[SNAP CHOICE] INPUT→OUTPUT closer (15.2px < 25.3px) → Turn Left
[SNAP CHOICE] INPUT→OUTPUT closer (12.8px < 28.1px) → Turn Left
[SNAP CHOICE] INPUT→OUTPUT closer (20.5px < 22.1px) → Turn Right  ← переключение!
[SNAP CHOICE] INPUT→OUTPUT closer (25.1px < 20.8px) → Turn Right
```

### Шаг 5: РЕЗУЛЬТАТ ТЕСТА
```
✓ PASS:
  - При движении снизу вверх - плавное переключение целей
  - Переключение происходит когда расстояния примерно равны
  - Нет скачков/рывков в выборе целей

✗ FAIL:
  - Цель "прилипает" и не переключается
  - Переключение происходит слишком рано/поздно
  - В логах не видно переключения
```

## Тест 3: Все направления

### Сверху вниз (DOWN)
```
1. Возьмите любой блок
2. Двигайте ВНИЗ между двумя блоками
3. Проверьте что INPUT→OUTPUT переключается плавно
```

### Снизу вверх (UP)
```
1. Возьмите блок из нижней части цепи
2. Двигайте ВВЕРХ
3. Проверьте плавное переключение
```

### Влево-вправо (HORIZONTAL)
```
1. Возьмите блок
2. Двигайте ВЛЕВО или ВПРАВО
3. Проверьте что выбирается геометрически ближайший
```

### ИТОГ:
```
✓ PASS: Во всех направлениях выбирается ближайший OUTPUT
✗ FAIL: В некоторых направлениях "неправильное" поведение
```

## Тест 5: Обе линии + выбор

### Шаг 1: Поднесите блок так чтобы оба snap'а были возможны

```
Может быть сложная ситуация где и INPUT→OUTPUT и OUTPUT→INPUT возможны
```

### Шаг 2: Проверьте какой выбирается

```
[SNAP CHOICE] INPUT→OUTPUT closer (10.5px < 20.3px) → Block_2
             ↑ выбран INPUT→OUTPUT потому что ближе
```

### ИТОГ:
```
✓ PASS: Всегда выбирается ближайший (неважно INPUT или OUTPUT)
✗ FAIL: Выбирается неправильный тип snap'а
```

## Что смотреть в Console

```
Нормальные логи:
[SNAP CHOICE] INPUT→OUTPUT closer (10.5px < 20.3px) → Block_2
[SNAP CHOICE] OUTPUT→INPUT closer (15.2px < 25.1px) → Block_1
[SNAP CHOICE] Tie - INPUT→OUTPUT preferred (25.0px) → Block_3

Плохие логи:
[SNAP CHOICE] INPUT→OUTPUT closer (50.0px < 10.0px) → ← НЕПРАВИЛЬНО! 50 > 10
```

## Если что-то не работает

### Логирование не показывает выбор
- Проверьте что snap активен (должна быть линия)
- Откройте Console окно (может быть закрыто)
- Убедитесь что Play mode включен

### Выбирается неправильный блок
- Посмотрите логирование - там видны расстояния
- Смотрите визуальную линию - она показывает что выбрано
- Проверьте координаты в логах

### Snap вообще не работает
- Убедитесь что код скомпилировался без ошибок
- Проверьте что блоки имеют InputPoints и OutputPoints
- Смотрите логи [SNAP CHOICE] - должны быть
