# План тестирования приоритизированного магнитного притяжения (#10b Enhancement)

## Подготовка к тестированию

1. Откройте Unity проект
2. Откройте сцену **Assets/Scenes/GameScene.unity**
3. Нажмите Play для входа в режим редактирования программы
4. Откройте **Window → General → Console** для просмотра debug логов

## Тестовые сценарии

### Тест 1: Добавление в конец простой цепи

**Setup:**
- Добавьте блок "Move Forward" (A)
- Добавьте блок "Turn Left" (B) - он автоматически должен встать в конец

**Действие:**
1. Из палитры возьмите блок "Move Forward"
2. Перетащите его за INPUT (зелёную точку слева)
3. Подносите к OUTPUT (красной точке) блока B
4. Отпустите

**Ожидаемый результат:**
- Блок встанет в конец цепи: A → B → [New Move Forward]
- В консоли должны появиться логи:
  ```
  [SNAP READY INPUT→OUTPUT] MoveForward → TurnLeft | Distance: XX.XXpx
  [CONNECTION INPUT→OUTPUT] TurnLeft → MoveForward
  ```

**Проверка:** ✓ Пройдено / ✗ Не пройдено

### Тест 2: Добавление в конец длинной цепи (3+ блоков)

**Setup:**
- Создайте цепь: [Move Forward] → [Turn Left] → [Move Forward] → [Turn Right]
- У последнего блока (Turn Right) нет выхода

**Действие:**
1. Возьмите новый блок "Move Forward" за INPUT
2. Поднесите к OUTPUT блока "Turn Right" (последнего)
3. Отпустите

**Ожидаемый результат:**
- Система выберет OUTPUT Turn Right (Приоритет 1 - конец цепи)
- Новый блок встанет в конец
- Цепь: [Move] → [Turn] → [Move] → [Turn] → [New Move]

**Проверка:** ✓ Пройдено / ✗ Не пройдено

---

### Тест 3: Вставка в середину цепи (приоритизация между концом и серединой)

**Setup:**
- Цепь: [A] → [B] → [C]
- Блок A имеет OUTPUT, ведущий к B
- Блок B имеет OUTPUT, ведущий к C
- Блок C - конец цепи

**Действие:**
1. Возьмите новый блок X за INPUT
2. Поднесите между блоками B и C
3. **Важно:** OUTPUT B должен быть видим (середина) и OUTPUT C (конец)
4. Отпустите

**Ожидаемый результат:**
- Система выберет OUTPUT C (Приоритет 1 - конец цепи), а не OUTPUT B (Приоритет 2)
- Результат: A → B → C → X
- **Если вы хотите вставить в середину**, нужно поднести ближе к OUTPUT B!

**Альтернативное действие (для вставки в середину):**
1. Возьмите блок X за INPUT
2. Поднесите близко к OUTPUT B (между B и C)
3. Отпустите

**Ожидаемый результат для вставки в середину:**
- Результат: A → B → X → C
- Логи должны показать переподключение:
  ```
  [RECONNECT] B → X
  [DISCONNECT FOR INSERT] B → C
  ```

**Проверка:** ✓ Пройдено / ✗ Не пройдено

   - Отпустите

**Ожидаемый результат:**
- Цепь: A → B → C → X → D
- Все блоки выравнены, нет наложений
- Логи показывают правильные переподключения

**Действие:**
1. Возьмите новый блок X за OUTPUT (красная точка)
2. Поднесите одновременно ближе к INPUT A и INPUT D

**Ожидаемый результат:**
- Система выбирает INPUT с минимальным расстоянием среди Приоритета 1
- Оба INPUT (A и D) имеют Приоритет 1 (нет входящей связи)
- Выбирается тот, что ближе по расстоянию

## Замечания при тестировании

### Дебаг логи для проверки

Когда магнитный снап готов, вы должны видеть в Console:
```
[SNAP READY OUTPUT→INPUT] BlockName → TargetName | Distance: XX.XXpx
```

Когда снап применяется:
```
[SNAP APPLIED OUTPUT→INPUT] BlockName → TargetName
[CONNECTION OUTPUT→INPUT] BlockName → TargetName
[RETURN TO PROGRAM] BlockName returned to ProgramArea
```

Когда блок вставляется в середину:
```
[RECONNECT] BlockA → BlockNew
[DISCONNECT FOR INSERT] BlockA → BlockB
[ALIGN] BlockB aligned to BlockNew
[ALIGN] BlockC aligned to BlockPrevious
...
```

### Возможные проблемы

**Проблема:** Снап не срабатывает
- **Решение:** Убедитесь что расстояние <= 50px (snapDistance в SnapManager)

**Проблема:** Неправильный порядок выполнения
- **Решение:** Проверьте connectedTo связи в Inspector - они должны быть в правильном порядке

**Проблема:** Блоки наложены друг на друга
- **Решение:** Проверьте что AlignToInputConnection() вызывается правильно
