# Новый визуализатор линий магнитизма - SnapLineRenderer

**Дата:** 2026-01-14
**Статус:** ✓ Реализовано и готово к тестированию

## Что изменилось

### ❌ Проблемы старого подхода (Debug.DrawLine + Gizmos)
- Линия не видна в Game View для новых блоков с палитры
- Кружки (Gizmos) перекрывают друг друга
- Неясно какой коннектор к какому магнитится

### ✅ Новый подход (SnapLineRenderer)
- **Рисует настоящую линию** между коннекторами
- **Работает для всех блоков** (новых и существующих)
- **Видна в Game View** постоянно пока snap активен
- **Использует Image компонент** (встроенный Unity UI)

## Как это работает

### 1. SnapLineRenderer.cs (новый компонент)

Создаёт Image элемент с линией:
```csharp
// Автоматически создаёт UI Image на Canvas
// Позиционирует и вращает её между двумя точками
lineRenderer.DrawLine(fromPos, toPos, lineColor);
```

**Параметры:**
- `fromPos` - начало линии (выход/вход перетаскиваемого блока)
- `toPos` - конец линии (вход/выход целевого блока)
- `lineColor` - цвет линии (cyan для INPUT→OUTPUT, yellow для OUTPUT→INPUT)

### 2. Интеграция в BlockUI

При обновлении snap визуалов:
```csharp
// Ищет SnapLineRenderer в ProgramArea или rootCanvas
// Если не найден - создает автоматически на rootCanvas
lineRenderer.DrawLine(fromPos, toPos, lineColor);
```

**Преимущества:**
- Работает для новых блоков (с палитры) ✓
- Работает для существующих блоков ✓
- Автоматически создаёт визуализатор если его нет ✓

|----------|------|-----|----------|

## Инструкция для тестирования

### Step 1: Откройте GameScene и Play

```
Assets/Scenes/GameScene.unity → Play
```

### Step 2: Создайте цепь

```
Добавьте блоки:
1. [Move Forward]
2. [Turn Left]
3. [Move Backward]
```

### Step 3: Перетащите новый блок с палитры

```
1. Из палитры возьмите [Turn Right] за INPUT
2. Поднесите к OUTPUT последнего блока
3. СМОТРИТЕ В GAME VIEW
4. Должна появиться CYAN ЛИНИЯ от INPUT вашего блока к OUTPUT целевого
```

### Step 4: Перетащите существующий блок

```
1. Возьмите блок [Move Backward] за INPUT
2. Вставьте между [Move Forward] и [Turn Left]
3. Должна появиться CYAN ЛИНИЯ показывающая соединение
4. Блок встанет в правильную позицию
```

## Как это работает технически

### 1. DrawLine() вычисляет параметры линии:

```csharp
// Направление и расстояние
Vector2 direction = toPos - fromPos;
float distance = direction.magnitude;

// Положение - в центре между двумя точками
Vector2 midpoint = (fromPos + toPos) / 2f;

// Угол вращения
float angle = Mathf.Atan2(direction.y, direction.x) * Mathf.Rad2Deg;
```

### 2. Image компонент позиционируется:

```csharp
// RectTransform линии
lineRect.anchoredPosition = midpoint;      // Центр между точками
lineRect.rotation = Quaternion.AngleAxis(angle, Vector3.forward);
lineRect.sizeDelta = new Vector2(distance, 3f);  // Тонкая длинная линия
```

### 3. Каждый кадр обновляется:

```csharp
Update() → DrawLine() → UpdateLineVisuals()
```

Позволяет линии следовать за движением блока в реальном времени.

## Возможные проблемы и решения

### Проблема: Линия не видна

**Решение 1:** Проверьте что snap активен
```
[SNAP READY INPUT→OUTPUT] должна быть в консоли
```

**Решение 2:** Проверьте что Game View видна (не Scene View)

**Решение 3:** Убедитесь что блоки в Canvas (не в мировом пространстве)
- SnapLineRenderer работает только с UI Canvas
- Для 3D объектов нужен LineRenderer

### Проблема: Линия видна но неправильно ориентирована

**Решение:** Может быть проблема с преобразованием координат
- GetWorldPosition() должен возвращать экранные координаты
- Проверьте что это Vector2 (не Vector3)

### Проблема: Линия дёргается или мерцает

**Решение:** Это нормально - Update() рисует каждый кадр
- На 60 FPS это выглядит как плавное движение
- На низких FPS может быть заметнее
