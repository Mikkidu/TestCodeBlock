# Руководство тестирования - Каскадное выравнивание (#10b)

## Быстрая проверка перед детальным тестированием

### Предусловие
- Открыть GameScene в Unity Editor
- Нажать Play

---

## Тест 1: Базовая вставка в конец цепи

**Сценарий:** Вставка нового блока в конец существующей цепи

**Шаги:**
1. Перетащить **MoveForward** из палитры в ProgramArea
2. Перетащить **TurnRight** из палитры → поднести INPUT TurnRight к OUTPUT MoveForward
3. Результат должен быть: **MoveForward → TurnRight**
4. Перетащить **MoveBackward** из палитры → поднести INPUT MoveBackward к OUTPUT TurnRight
5. Результат должен быть: **MoveForward → TurnRight → MoveBackward**

**Проверки:**
- [ ] Все блоки видны в ProgramArea
- [ ] Блоки НЕ наложены друг на друга
- [ ] Коннекторы окрашены правильно (зеленый INPUT, красный OUTPUT)
- [ ] Консоль: логи `[CONNECTION OUTPUT→INPUT]` для каждого snap
- [ ] Консоль: НЕ должно быть ошибок

**Выполнение программы:**
1. Нажать Run
2. Проверить логи:
   ```
   [EXECUTE] Robot executing: MoveForward
   [EXECUTE] Robot executing: TurnRight
   [EXECUTE] Robot executing: MoveBackward
   [PROGRAM COMPLETE]
   ```
3. [ ] Каждая команда выполнена ОДИН раз (не дважды!)

## Тест 2: Вставка в начало цепи

**Сценарий:** Вставка нового блока ПЕРЕД началом цепи

**Шаги:**
1. Создать цепь: **MoveForward → TurnRight** (как в Тесте 1)
2. Перетащить **MoveBackward** из палитры
3. Поднести **OUTPUT MoveBackward** к **INPUT MoveForward**
   - Должны появиться желтые коннекторы
4. Отпустить блок

**Ожидаемый результат:** **MoveBackward → MoveForward → TurnRight**

**Проверки:**
- [ ] Визуальный feedback работал (желтые коннекторы видны)
- [ ] MoveBackward позиционирован ДО MoveForward
- [ ] Консоль: `[CONNECTION OUTPUT→INPUT] MoveBackward → MoveForward`
- [ ] Консоль: нет ошибок `DISCONNECT FOR INSERT` (в начало не должно быть)

**Выполнение программы:**
1. Нажать Run
2. Проверить логи - должны выполняться в новом порядке:
   ```
   [EXECUTE] Robot executing: MoveBackward
   [EXECUTE] Robot executing: MoveForward
   [EXECUTE] Robot executing: TurnRight
   ```

## Тест 3: КРИТИЧНЫЙ - Вставка в середину цепи (Cascade Test)

**Сценарий:** Вставка блока МЕЖДУ двумя существующими - проверить каскадное выравнивание

**Шаги:**
1. Создать цепь: **MoveForward → TurnLeft → TurnRight** (3 блока)
2. Перетащить **MoveBackward** из палитры
3. Поднести **OUTPUT MoveBackward** к **INPUT TurnLeft** (НЕ к TurnRight!)
   - Должны появиться желтые коннекторы (OUTPUT MoveBackward + INPUT TurnLeft)
4. Отпустить блок

**Ожидаемый результат:** **MoveForward → MoveBackward → TurnLeft → TurnRight**

**Проверки на вставку:**
- [ ] Визуальный feedback работал (желтые коннекторы)
- [ ] MoveBackward позиционирован между MoveForward и TurnLeft
- [ ] TurnLeft АВТОМАТИЧЕСКИ сместился вниз (cascade выравнивание)
- [ ] TurnRight АВТОМАТИЧЕСКИ сместился вниз (cascade продолжился)

**Консоль - должны быть логи:**
```
[DISCONNECT FOR INSERT] MoveForward → TurnLeft
[RECONNECT] MoveForward → MoveBackward
[CONNECTION OUTPUT→INPUT] MoveBackward → TurnLeft
[ALIGN] TurnLeft aligned to MoveBackward
[ALIGN] TurnRight aligned to TurnLeft
```

**Визуальная проверка:**
- [ ] Блоки выровнены вертикально в одну линию (без перекрытия)
- [ ] Коннекторы выравнены по вертикали (INPUT одного к OUTPUT другого)
- [ ] Нет пробелов между блоками, нет наложения

**Выполнение программы:**
1. Нажать Run
2. Проверить логи - должны выполняться в новом порядке:
   ```
   [EXECUTE] Robot executing: MoveForward
   [EXECUTE] Robot executing: MoveBackward
   [EXECUTE] Robot executing: TurnLeft
   [EXECUTE] Robot executing: TurnRight
   [PROGRAM COMPLETE]
   ```

## Тест 4: Множественные вставки подряд

**Сценарий:** Несколько вставок в цепь - проверить стабильность

**Шаги:**
1. Начать с пустой ProgramArea
2. Добавить **MoveForward**
3. Добавить **TurnRight** в конец: **MoveForward → TurnRight**
4. Добавить **TurnLeft** в конец: **MoveForward → TurnRight → TurnLeft**
5. Вставить **MoveBackward** между MoveForward и TurnRight:
   - **MoveForward → MoveBackward → TurnRight → TurnLeft**
6. Вставить второй **MoveBackward** между MoveBackward и TurnRight:
   - **MoveForward → MoveBackward → MoveBackward → TurnRight → TurnLeft**

**Проверки:**
- [ ] После каждой вставки все блоки остаются видимы
- [ ] После каждой вставки cascade выполняется корректно
- [ ] Консоль: нет дублирования логов
- [ ] Консоль: нет ошибок

**Выполнение программы:**
1. Нажать Run
2. Проверить логи - все блоки выполняются в правильном порядке

## Тест 5: Проверка визуального выравнивания

**Сценарий:** Убедиться что визуальное выравнивание точное (коннекторы совпадают)

**Шаги:**
1. Создать цепь: **A → B → C** (используйте любые блоки)
2. Вставить **X** между **A** и **B**
3. МЕДЛЕННО переместить **X** немного в сторону (перетащить и отпустить)
4. Проверить что коннекторы все еще совпадают

**Визуальная проверка:**
- [ ] Когда блок на месте - OUTPUT одного совпадает визуально с INPUT следующего
- [ ] После перемещения X все коннекторы остаются выровнены
- [ ] Нет зазоров между точками соединения
- [ ] Нет наложения блоков друг на друга

## Тест 7: GetFirstBlock() - правильное определение начального блока

**Сценарий:** Убедиться что GetFirstBlock() находит блок с нулевыми входящими соединениями

**Шаги:**
1. Создать цепь: **A → B → C**
2. Переместить существующий блок **C** (перетащить из программы)
3. Поднести OUTPUT C к INPUT A (вставить C в начало)
4. Результат: **C → A → B** (C теперь первый блок)
5. Запустить программу

**Проверки:**
- [ ] GetFirstBlock() вернул C (блок без входящих соединений)
- [ ] Выполнение началось с C, а не с A

**Консоль:**
```
[EXECUTE] Robot executing: C
[EXECUTE] Robot executing: A
[EXECUTE] Robot executing: B
```

## Если обнаружены проблемы

### Проблема: Блоки наложены друг на друга
**Возможные причины:**
- AlignToInputConnection() не был вызван
- GetWorldPosition() возвращает неправильные координаты
- offset расчет неверен

**Отладка:**
1. Включить Debug.Log в AlignToInputConnection()
2. Проверить что логи `[ALIGN]` появляются в консоли
3. Проверить что offset вычисляется (добавить `Debug.Log($"Offset: {offset}")`)

### Проблема: Коннекторы не совпадают визуально
**Возможные причины:**
- RectTransform.position изменяется неправильно
- Используются anchoredPosition вместо position

**Отладка:**
1. Добавить логи позиции до и после смещения
2. Проверить что используется `rect.position` (мировые координаты)

### Проблема: Cascade не продолжается (только B смещается, C нет)
**Возможные причины:**
- GetNextBlock() вернул null
- nextBlock.AlignToInputConnection() не вызывается

**Отладка:**
1. Добавить Debug.Log перед вызовом cascade
2. Проверить что GetNextBlock() вернул правильный блок

### Проблема: GetFirstBlock() возвращает неправильный блок
**Возможные причины:**
- Логика поиска блока без входящих соединений неверна
- connectedTo не проверяется правильно

**Отладка:**
1. Проверить логику в ProgramArea.GetFirstBlock()
2. Убедиться что проверяется `output.connectedTo == inputPoint`
