## Основные тестовые сценарии (в порядке сложности)

### Быстрый тест (2 минуты)

1. **Добавьте 2 блока в цепь:**
   - Из палитры -> Move Forward (A)
   - Из палитры -> Turn Left (B) - встанет в конец

2. **Добавьте третий блок в конец:**
   - Возьмите Move Forward (C) за INPUT
   - Поднесите к OUTPUT блока B
   - Отпустите
   - **Результат должен быть:** A → B → C

3. **Нажмите Run, посмотрите логи в консоли**

### Стандартный тест (5 минут)

1. **Постройте цепь из 4 блоков:** A → B → C → D
2. **Вставьте блок X в середину между B и C:**
   - Возьмите X за INPUT
   - Поднесите к OUTPUT B (близко, но не к OUTPUT D!)
   - Отпустите
   - **Результат должен быть:** A → B → X → C → D

3. **Нажмите Run, проверьте порядок выполнения**

## На что смотреть при тестировании

### ✓ Должно быть правильно

- Блоки встают в конец цепи, когда их INPUT близко к OUTPUT последнего блока
- Блоки вставляются в середину, когда их INPUT близко к OUTPUT середины
- После Run блоки выполняются в правильном порядке (A → B → C → D)
- Нет наложения блоков, всё выровнено красиво

### ✗ Если что-то не так

- Блоки цепляются за середину вместо конца → проверьте логи приоритета
- Программа выполняется в неправильном порядке → проверьте connectedTo в Inspector
- Блоки наложены → проверьте AlignToInputConnection()

## Логи для проверки

При наведении (DRAG):
```
[SNAP READY OUTPUT→INPUT] BlockName → TargetBlock | Distance: XX.XXpx
```

При отпускании (DROP):
```
[SNAP APPLIED OUTPUT→INPUT] BlockName → TargetBlock
[CONNECTION OUTPUT→INPUT] BlockName → TargetBlock
```

При вставке в середину:
```
[RECONNECT] BlockA → BlockX
[DISCONNECT FOR INSERT] BlockA → BlockB
[ALIGN] BlockB aligned to BlockX
```
