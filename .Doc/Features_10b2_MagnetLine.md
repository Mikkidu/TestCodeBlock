# Feature #10b.2: Визуализация линии магнитизма

**Дата реализации:** 2026-01-14
**Статус:** ✓ РЕАЛИЗОВАНО (Debug версия)
**Приоритет:** 🟠 HIGH

## Описание

Добавлена визуальная линия между коннекторами при магнитном притяжении. Линия помогает пользователю понять к какому блоку будет произведён снап во время перетаскивания.

## Реализация

### Метод: Debug.DrawLine в UpdateSnapVisuals()

Добавлена визуализация в методе `UpdateSnapVisuals()` класса `BlockUI`:

#### Для OUTPUT→INPUT snap (добавление в конец цепи):

```csharp
// Draw magnetic line from dragging OUTPUT to target INPUT (debug)
if (outputPoints.Count > 0 && outputPoints[0] != null)
{
    Vector3 fromPos = outputPoints[0].GetWorldPosition();
    Vector3 toPos = snapInfo.targetConnector.GetWorldPosition();
    Debug.DrawLine(fromPos, toPos, new Color(1f, 1f, 0f, 1f), 0f);  // Yellow line
}
```

**Цвет:** Жёлтый (1f, 1f, 0f, 1f)
**Направление:** От OUTPUT перетаскиваемого блока → к INPUT целевого блока
**Видимость:** Game View

#### Для INPUT→OUTPUT snap (вставка в цепь):

```csharp
// Draw magnetic line from dragging INPUT to target OUTPUT (debug)
if (inputPoints.Count > 0 && inputPoints[0] != null)
{
    Vector3 fromPos = inputPoints[0].GetWorldPosition();
    Vector3 toPos = snapInfo.targetConnector.GetWorldPosition();
    Debug.DrawLine(fromPos, toPos, new Color(0f, 1f, 1f, 1f), 0f);  // Cyan line
}
```

**Цвет:** Cyan (0f, 1f, 1f, 1f)
**Направление:** От INPUT перетаскиваемого блока → к OUTPUT целевого блока
**Видимость:** Game View

### Как это работает

1. **OnDrag() вызывает UpdateSnapVisuals()** для каждого кадра
2. **Если snapInfo.canSnap == true:**
   - Коннекторы подсвечиваются жёлтым
   - **Debug.DrawLine() рисует линию** от коннектора перетаскиваемого к целевому
3. **Если snapInfo.canSnap == false:**
   - Коннекторы возвращают стандартные цвета
   - Линия не рисуется

### Особенности Debug.DrawLine

- ✓ Видна в Game View в реальном времени
- ✓ Автоматически исчезает каждый кадр (используется 0 duration)
- ✓ Не требует создания дополнительных объектов
- ✓ Низкая производительность (просто линия для визуализации)
- ✓ Видна только в Play режиме

| Нет snap | Нет линии | - | Магнитизм невозможен |

## Использование в Play режиме

1. **Откройте Game View** (нижняя часть экрана или отдельное окно)
2. **Нажмите Play** в редакторе
3. **Перетащите блок:**
   - Когда магнитизм активен → видна цветная линия
   - Линия показывает направление будущего соединения
4. **Отпустите блок** для завершения снапа

## Отладка

### Если линия не видна:

1. **Проверить что магнитизм работает:**
   - Коннекторы должны быть подсвечены жёлтым ✓
   - Консоль должна показать логи SNAP READY ✓

2. **Проверить Game View:**
   - Убедитесь что это Game View, а не Scene View
   - Попробуйте перетащить блок поближе

3. **Проверить Debug режим:**
   - Debug.DrawLine видны только в Play режиме
   - Попробуйте добавить Debug.Log рядом с DrawLine

### Если линия идёт в неправильную сторону:

- Проверить GetWorldPosition() возвращает правильные координаты
- Проверить что fromPos и toPos не null

## Тестирование

### Быстрый тест (1 мин):

1. Play в сцене
2. Создайте 2 блока A, B
3. Возьмите новый блок X за INPUT
4. Поднесите к OUTPUT B
5. **Ожидание:** Видна жёлтая линия от INPUT X к OUTPUT B

2. Возьмите существующий блок D
3. Вставьте в середину между B и C
4. **Ожидание:** Видна cyan линия от OUTPUT D к INPUT C
